# ТЕХКАРТА: Сноубордический чехол

Артикул: SB-146 · Размер: 146 см · Дата: 30.05.2024

## Спецификация

Внешний размер: 146 × 32 × 17 см. Чехол-конверт: две основные панели, боковая стенка по периметру, молния №10 двухзамковая по периметру + карман, ручка, наплечный ремень на полукольцах, стропа 25 мм пришита к основе, окантовка по периметру.

## Последовательность операций

1. Раскрой деталей по лекалам.
2. Дублирование утеплителем панелей и стенки.
3. Пришивание стропы 25 мм к основе (на 8–10 см).
4. Установка молнии по периметру.
5. Сборка кармана (трапеция), установка замка.
6. Соединение панелей со стенкой, двойная строчка.
7. Окантовка по периметру.
8. Установка фастексов, полуколец, регуляторов. Проверка ОТК.

## Примечания

Допуск на размеры ±1 см. Швы — двойная строчка. Цвет — бежевый/серый (по согласованию).
