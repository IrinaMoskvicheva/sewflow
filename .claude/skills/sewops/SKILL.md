# sewops — работа с репозиторием sewflow

Скилл-проводник по проекту. Применяй его правила при любой задаче в этом репозитории.

## 1. Структура проекта (ориентируйся, не перечитывая всё)

```
sewflow/
├─ app.py                  # Flask-интерфейс (маршруты: / , /costing, /view/<папка>/<файл>)
├─ modules/costing.py      # калькулятор себестоимости: техкарта md + прайс Google Sheets → HTML-дашборд
├─ templates/index.html    # UI, тёмная тема, 2 вкладки (Техкарты / Себестоимость)
├─ .claude/skills/         # tcgen (техкарта по эскизу), tkcost (себестоимость), sewops
├─ sketches/               # вход tcgen: ручные эскизы «<название> <размер>.png»
├─ tech_maps/              # техкарты md + чертежи png, то же имя
├─ cost_reports/           # HTML-дашборды себестоимости
├─ screenshots/            # скриншоты для README
├─ .env                    # ключи (НЕ коммитить, в .gitignore)
└─ .env.example            # шаблон конфига
```

Ключевые договорённости:
- Имя файла повсюду: `<название изделия> <размер>` (пример: `сноуборд 145`).
- Таблица «Материалы» в техкарте — строго `| Материал | Расход на изделие | Ед. изм. | Комментарий |`: её парсит `costing.parse_materials()`.
- Названия материалов должны совпадать со строками прайса в Google Sheets (`MATERIALS_PRICE_SHEET` в `.env`).
- Секреты — только в `.env`. В репозиторий попадает лишь `.env.example`. Ссылку на прайс можно коммитить, ключи — нет.

## 2. Запуск сервиса

Python живёт по пути `%LOCALAPPDATA%\Programs\Python\Python312\python.exe` (в PATH его нет).

```bash
"$LOCALAPPDATA/Programs/Python/Python312/python.exe" app.py   # фоном: run_in_background
```

Проверка: `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:5000/` → ожидается 200.
Перед запуском убедись, что порт 5000 свободен или останови старый фоновый процесс (TaskStop).

## 3. Внесение изменений

- План на утверждение — только для сложных задач (новые модули, смена архитектуры); мелкие правки — сразу.
- Стиль кода: Python, комментарии-описания в docstring каждого модуля, тёмная тема в HTML (CSS-токены `--bg/--panel/--accent` — не вводи новые цвета без нужды).
- Удаление/переименование файлов — только с явного разрешения пользователя.
- После изменений: перезапусти Flask и проверь затронутые маршруты curl-ом.

## 5. Проверка ошибок

Чек-лист перед коммитом:
1. `python -m modules.costing <техкарта>.md` — расчёт проходит, итог адекватен (сотни ₽, не десятки тысяч — большой итог = ошибка сопоставления с прайсом).
2. Flask поднимается без traceback; GET `/` и `/view/...` → 200.
3. В техкартах таблица «Материалы» читается калькулятором (нет позиций «Не учтено» без причины).
4. `git status` — нет `.env`, логов, `__pycache__`; только осмысленные файлы.
5. Типичные грабли: цена из прайса берётся из колонки «факт», иначе «план»; нечёткое совпадение названий в `find_price()` — при промахе правь словарь названий в техкарте под прайс, а не наоборот.


- Перед пушем прогони чек-лист из п. 5.

## 7. Чего не делать

- Не коммитить `.env`, секреты, токены.
- Не выводить значение `PROXYAPI_KEY` в чат.
- Не менять формат таблицы «Материалы» и шаблона имён файлов — на них завязаны tcgen/tkcost/costing.
