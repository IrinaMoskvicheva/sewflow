# Шаблон чертежа раскладки кроя (tcgen)

Правила оформления итогового чертежа `tech_maps/<название> <размер>.png`.
Промпт для gpt-image-2 строится по этому шаблону; расшифровка эскиза (Read)
подставляется в промпт, контуры берутся image-to-image из эскиза.

## Стиль

- Чёрный контурный чертёж на белом фоне, индустриальный стиль лекального листа.
- Детали кроя расположены как на эскизе пользователя; пропорции выровнены
  под реальные размеры из техкарты (если на эскизе деталь нарисована квадратной,
  а по размерам она 152×32 — на чертеже она вытянутая).
- Контуры — как на эскизе: округлые/сужающиеся торцы, изгибы, трапеции.
  Не «выпрямлять» детали до прямоугольников.

## Нумерация деталей

- Каждая деталь — жирный номер в кружке в центре детали: ①, ②, ③…
- Нумерация с 1, без пропусков; количество деталей = последнему номеру.
- Номера на чертеже строго совпадают с таблицей «Детали кроя» в техкарте.
- Мелкая фурнитура (карабины, фастексы) может иметь свой номер, если она
  пронумерована на эскизе.

## Размеры

- На каждую деталь — размерные линии со стрелками и значениями в см.
- Формат: `<длина> см` над длинной стороной, `<ширина> см` справа от короткой.
- Трапеции и фигурные детали: размеры по основаниям и высоте
  (например, карман: верх 30 см / низ 36 см / высота 13 см).
- Значения — только из техкарты (с припусками), не «на глаз» с рисунка.

## Комментарии на чертеже (допустимы и приветствуются)

Переносить с эскиза актуальные для производства, расшифровывая почерк:

- фурнитура с параметрами: «стропа 2,5 см, ℓ=100 см», «фастекс 2,5»,
  «полукольца 4 см», «молния №10»;
- функциональные пометки: «ручка», «наплечный ремень ℓ=140 см»,
  «накладной карман на липучке», «центр»;
- цвет: «деталь ② — цвет/принт, остальные — чёрные»;
- состав слоёв — только в штампе спецификации (см. ниже), не у деталей.

Не дословно: очевидные ошибки расшифровки исправлять по техкарте
(«зимой» → «слоя», «месна» → «пена»).

## Штамп спецификации — правый нижний угол

Рамка с заголовком изделия и краткой спецификацией:

```
┌───────────────────────────────┐
│ ЧЕХОЛ ДЛЯ СНОУБОРДА 150       │
│ Внешний размер: 152 × 32 см   │
│ Все детали — 3 слоя:          │
│ оксфорд 600D + пена 3 мм +    │
│ оксфорд 200Д                  │
│ Деталь ② — цвет/принт,        │
│ остальные — чёрные            │
└───────────────────────────────┘
```

Содержимое штампа = раздел «Спецификация» из техкарты, свёрнутый до
3–6 строк. Даты, имена, номера ревизий не указывать.

## Чего на чертеже быть не должно

- Лишних деталей, которых нет в таблице «Детали кроя».
- Фоновой сетки, теней, цветной заливки деталей.
- Текста, не относящегося к изделию (подписи модели, водяные знаки).
